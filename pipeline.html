建议的分析框架

把综述里的结论翻成一套可在自己 WES / RNA-seq 上跑的步骤。目标不是再发一篇“胃癌突变谱”，而是回答：共突变组合如何在原发与淋巴结之间被保留或改写。

0. 开始前先盘点样本

理想设计

  • 同一患者：正常对照 + 原发灶 + 至少 1 枚阳性淋巴结
  • WES 与 RNA-seq 来自同一块或紧邻切片
  • 记录 Lauren 分型、部位、pTNM、HER2、EBV、MSI、治疗史

常见妥协

  • 只有原发 WES + 部分配对淋巴结
  • RNA 与 DNA 不是同一区域 → 解释 ASE 时要谨慎
  • 无正常对照 → 需公共数据库过滤并在局限中写明
Sundar 的教训：原发若只是黏膜活检，会漏掉深部 / 转移克隆。报告里应标明取样深度。

1. WES 基础层

  1. 体细胞 SNV/indel：Mutect2 + Strelka2 交集。
  2. 拷贝数与纯度 / 倍性：FACETS、ASCAT 或 Sequenza。
  3. MSI / TMB：MSIsensor-pro。MSI-high 必须单独做共突变检验。
  4. 驱动注释：OncoKB / CIViC + 胃癌高频名单（TP53、ARID1A、CDH1、RHOA、PIK3CA、SMAD4、APC、ERBB2 等）。
  5. 融合候选：CLDN18–ARHGAP 建议用 RNA 复核。

2. 把突变切成三层

层定义含义
Trunk两侧都在且 CCF 高起始/维持事件
Shared-subclonal两侧都在但 CCF 低或不对称多克隆播种痕迹
Primary-private仅原发未播种侧支或转移后丢失
LN-private仅淋巴结播种后获得，或原发未取到的深部克隆

工具：PyClone-VI / Pairtree 估 CCF；Treeomics / MACHINA 推迁移方向。

3. 共突变统计

不要只做全队列 Fisher。用 maftools::somaticInteractions 探索，用 DISCOVER / SelectSim 做负荷校正；至少分层非 MSI。预先检验：TP53×CDH1；CDH1×ARID1A/DDR；CDH1/RHOA×CLDN18-ARHGAP；TP53×ERBB2/CCNE1 扩增。

4. RNA-seq 对接

  1. 融合：Arriba / STAR-Fusion
  2. ASE：看驱动突变是否被转录
  3. 差异表达先做纯度校正或解卷积
  4. 按共突变基因型分组看通路 GSVA
框架是研究设计建议，参数需按测序深度与肿瘤纯度调整。
