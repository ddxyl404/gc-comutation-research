## 开启 GitHub Pages

1. 打开仓库 **Settings → Pages**
2. Source 选 **Deploy from a branch**
3. Branch 选 `main`，文件夹选 `/ (root)`
4. 保存后约 1 分钟可访问 `https://ddxyl404.github.io/gc-comutation-research/`

若改用 GitHub Actions，把 Pages source 改成 **GitHub Actions**（仓库内已有 `.github/workflows/pages.yml`）。
