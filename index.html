takeaways

先记住这五条

1. 胃癌不是一种病

EBV / MSI / GS / CIN 四型的驱动基因、突变负荷和转移偏好不同。共突变必须按亚型分层，否则会把互斥误判成共现。

2. TP53 常是主干

多区域与配对研究里，TP53 突变多为克隆性、原发与转移共享。它更像“已发生”的早期事件，而不是转移特异事件。

3. 互斥里藏着两条路

TP53 与 CDH1 倾向互斥；CDH1 常与 ARID1A / DDR 共现。肠型 CIN 与弥漫型 GS 走的不是同一条分子路径。

4. 淋巴结更像“深部原发”

Sundar 等发现淋巴结转移的转录组和突变更接近原发灶深部，而不是黏膜活检能取到的浅表区域。
