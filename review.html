胃癌共突变：
从分子分型到淋巴转移

面向拥有 WES / RNA-seq、希望做共突变与原发–淋巴结比较的研究者。文献条目见 文献表。

1. 为什么要做共突变

胃癌的基因组不是单基因故事，而是共改变组合，再加上原发与转移之间的不一致。Pectasides 等在胃食管腺癌中见到：原发与同步转移之间 SNV/indel 不一致约 40%，扩增不一致可到约 60%；据此重新分配治疗的患者达 32%。

共突变有三层用途：互斥常提示通路冗余；共享突变定义肿瘤主干；组合突变可能改变免疫表型与药物敏感性。

2. 先分层再谈共突变

EBV

PIK3CA、ARID1A 很常见，TP53 少见，常有 PD-L1/L2 扩增。

MSI

超突变。共突变检验必须单独做，否则被负荷带偏。

GS

弥漫型为主。CDH1、RHOA、CLDN18–ARHGAP 是标志。

CIN

肠型为主。TP53 + ERBB2/CCNE1/FGFR2/KRAS 等扩增。

实操：至少分成 MSI-high vs 非 MSI；最好再按 CIN-like 与 GS-like 分开。

3. 共现与互斥的主要格局

TP53 是最常见驱动突变，多为克隆性主干。TP53 野生型更常见 MDM2/CDK4 扩增、ARID1A、PIK3CA、CDH1。中国队列中 HiC 富集 TP53、LoC 富集 ARID1A。

CDH1 与 TP53 / APC 倾向互斥，与 ARID1A 及 DDR 基因倾向共现；PD-L1 更低，有 PARP / Wee1 敏感线索。CLDN18–ARHGAP 融合与 CDH1 / RHOA 互斥——同一条黏附–RHO 轴只需被打穿一次。

组合关系背景
TP53 × 拷贝数 / ERBB2 amp共现CIN / 肠型
TP53 × CDH1倾向互斥肠型 vs 弥漫型
CDH1 × ARID1A / DDR共现弥漫型、TP53-WT
CDH1 / RHOA × CLDN18-ARHGAP互斥GS
PIK3CA × EBV / MSI共现亚型标志

4. 原发灶与淋巴结转移

Lee 2019（15 对 WES）：突变负荷相当，但 overlap 差异很大。TP53 几乎总是共同突变；原发特异可见 SMARCA4，淋巴结特异可见 CTNNB1。系统发育支持淋巴结来自原发中相对均质的亚克隆。

Lee 2020（10 例、106 个区域）：TP53 多为跨部位的克隆突变。单克隆原发的转移保持相同组成（26/26）；多克隆原发以多克隆播种为主（37/44）。

Sundar 2021：浅表 vs 深部 43% 基因差异表达，深部 vs 淋巴结仅 16%。40% 突变只在深部和/或淋巴结。结论：区域淋巴结转移很可能起源于原发灶深部。只做胃镜黏膜活检会系统低估转移相关改变。

Oh 2023：血行转移更多染色体不稳定和新发扩增；腹膜转移更常保持染色体稳定。血行/腹膜转移的基因组距离有时比淋巴结更接近原发；每一枚淋巴结都可以是相对独立事件。

5. RNA-seq 能补什么

  1. 验证突变是否表达（ASE）。
  2. 捕捉融合（CLDN18–ARHGAP、FGFR2 等）。
  3. 把共突变映射到通路活性。
  4. 解卷积微环境，避免把淋巴结的细胞组成差异当成转移程序。

6. 尚未闭合的问题

  • 配对原发–淋巴结的共突变动态仍薄，少有校正纯度与亚型的统计框架。
  • 淋巴结是独立播种还是中转站，证据冲突。
  • 扩增不一致高于点突变，共扩增如何与共突变一起建模尚不统一。
  • 多数配对研究 n 很小（10–15 例）。

7. 对自身队列的含义

  1. 在非 MSI 样本中重现或修正 TP53–CDH1 互斥、CDH1–ARID1A 共现。
  2. 把突变分成 trunk / primary-private / LN-private。
  3. 用 RNA 检查 trunk 突变是否表达、LN-private 是否伴随可解释的转录程序。
  4. 若有多枚淋巴结，检验“每枚相对独立”还是“来自同一亚克隆”。
